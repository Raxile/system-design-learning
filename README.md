# system-design-practice

Hands-on preparation for **SDE2 system design interviews**, with a focus on
**crypto exchange / fintech** systems (e.g. Binance). The goal is to learn
backend and system design **by doing** — designing, building small working
implementations, and stress-testing my own understanding — not just reading.

I'm a frontend developer (React/JS) leveling up into backend and distributed
systems. Each topic gets a **design doc** (`docs/`), a **small working
implementation** in Node.js/TypeScript (`projects/`), and notes on what I
actually learned.

See [INDEX.md](INDEX.md) for the full learning index — every topic and fundamental
with a ready-to-paste AI mentor prompt. See [topics.md](topics.md) for the
prerequisite concepts to learn before each project.
